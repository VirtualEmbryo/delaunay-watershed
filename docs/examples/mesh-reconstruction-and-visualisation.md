# Mesh reconstruction and visualisation

Reconstruct the multimaterial mesh of a cell aggregate (`data/Images/1.tif`, in the repository), scale it, centre it, save it as `.rec` and `.vtk`, and show it in the Polyscope viewer. `1.tif` records no voxel size, so the sizes the notebook uses to scale the mesh are illustrative.

Data: the repository's `data/Images/`.

The notebook: [`Examples/example_1_mesh_reconstruction_visualisation.ipynb`](https://github.com/VirtualEmbryo/delaunay-watershed/blob/v0.7.0/Examples/example_1_mesh_reconstruction_visualisation.ipynb).
