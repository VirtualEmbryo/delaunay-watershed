# The `dw2d` package

The names `dw2d` exports (`dw2d.__all__`). The names of dw2d 0.1.5 that are not listed here still resolve through 0.8.x, with a `DeprecationWarning` (see [migrating from dw2d 0.1.5](../two_dimensional/migration-from-0.1.5.md)).
